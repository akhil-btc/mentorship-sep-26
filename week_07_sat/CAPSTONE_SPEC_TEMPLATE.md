## 3. What does the user do? What does the tool do back?

The user types / clicks / submits what? The tool responds with what? Walk through it in three to five steps. Example:

  1. User picks a financial concept from a menu.
  2. User writes a short explanation of that concept in their own words.
  3. Tool evaluates the explanation against a rubric.
  4. Tool returns a scored rubric + three revision questions.
  5. User revises the explanation and re-runs.

## 5. What is your tool NOT allowed to do?

Every good AI tool has a rule it will not cross. For e.g.: do not rewrite the student's essay. For a financial literacy tool: it might be "do not give specific investment advice" or "do not quote current market prices."
